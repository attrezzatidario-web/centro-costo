Budget annuale

Intelligenza artificiale

L'IA (Gemini o ChatGPT) legge le fatture, classifica gli articoli e analizza le spese.

Stato
Chiave API di Gemini (Google)Su aistudio.google.com → «Get API key». Resta salvata nello script Google, non sul telefono.
Chiave API di ChatGPT (OpenAI)Su platform.openai.com → «API keys» → «Create new secret key» (inizia con sk-). Serve credito su platform.openai.com › Billing. Resta salvata nello script Google, non sul telefono.
IA da usare per primaSe dà errore (credito finito, sovraccarico) si passa da sola all'altra.
Classifica le voci in «Altro»L'IA assegna una categoria agli acquisti di attrezzatura che non ne hanno una.
